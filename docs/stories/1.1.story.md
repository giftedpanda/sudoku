# Story 1.1: Project Scaffolding

## Status
Draft

## Story
**As a** developer,
**I want** a fully configured Next.js project with TypeScript, Tailwind CSS, and Vitest,
**so that** I can begin building features on a solid foundation.

## Acceptance Criteria
1. Running `pnpm dev` starts a Next.js dev server on localhost:3000 without errors
2. Running `pnpm build` produces a static export in the `out/` directory
3. Running `pnpm test` executes Vitest and passes a trivial smoke test
4. Running `pnpm lint` runs ESLint with no errors
5. TypeScript strict mode is enabled and `pnpm type-check` passes
6. Tailwind CSS 4+ is configured and utility classes render correctly
7. `next.config.ts` has `output: 'export'` for static site generation
8. The project has the full directory structure as defined in the architecture doc

## Tasks / Subtasks
- [ ] Initialize project with `pnpm create next-app` (App Router, TypeScript, Tailwind, ESLint)
- [ ] Configure `next.config.ts` with `output: 'export'`
- [ ] Install and configure Vitest with `@testing-library/react` and `jsdom`
- [ ] Install `clsx` and `tailwind-merge`; create `src/lib/utils.ts` with `cn()` helper
- [ ] Create all directories: `src/components/ui/`, `src/components/game/`, `src/hooks/`, `src/lib/`, `src/types/`, `src/config/`
- [ ] Create placeholder `src/types/index.ts` and `src/config/constants.ts` (empty exports)
- [ ] Add a smoke test (`src/app/page.test.tsx`) that renders the page
- [ ] Add `type-check` and `test:watch` scripts to `package.json`
- [ ] Verify all commands: `pnpm dev`, `pnpm build`, `pnpm test`, `pnpm lint`, `pnpm type-check`
- [ ] Self-verify with Definition of Done

## Dev Notes

### Architecture Context
This is the foundation story. Every other story depends on this. The project is a single-page static-export Next.js app. There is no backend, no API routes, no middleware.

### File Locations
| Purpose | Path |
|---------|------|
| Next.js config | `next.config.ts` |
| Root layout | `src/app/layout.tsx` |
| Main page | `src/app/page.tsx` |
| Global CSS | `src/app/globals.css` |
| Vitest config | `vitest.config.ts` |
| Utility function | `src/lib/utils.ts` |
| Type definitions | `src/types/index.ts` |
| Constants | `src/config/constants.ts` |
| Package config | `package.json` |

### Key Patterns to Follow
- Use `pnpm` exclusively (never npm or yarn)
- App Router with `src/` directory
- Strict TypeScript (`"strict": true` in tsconfig)
- Static export: `output: 'export'` in next.config.ts

### Dependencies
**NPM packages:**
- next, react, react-dom (from create-next-app)
- typescript, @types/react, @types/node (from create-next-app)
- tailwindcss (from create-next-app)
- eslint, eslint-config-next (from create-next-app)
- vitest, @testing-library/react, @testing-library/jest-dom, jsdom (dev)
- clsx, tailwind-merge (runtime)

**Story dependencies:** None (first story)
