# Story 2.7: Game Timer

## Status
Draft

## Story
**As a** player,
**I want** to see a running timer tracking how long I've been solving the puzzle,
**so that** I can track my progress and challenge myself to improve.

## Acceptance Criteria
1. A timer is displayed in the game header showing elapsed time in MM:SS format
2. The timer starts when the game begins (or resumes from saved state)
3. The timer increments every second
4. The timer pauses when the game is complete
5. The timer value is stored in game state for auto-save purposes
6. The timer displays correctly for times over 59:59 (shows HH:MM:SS)

## Dev Notes

### Architecture Context
The timer is managed as a combination of:
1. `useTimer` hook — handles `setInterval` for ticking every second
2. `TICK_TIMER` reducer action — increments the `timer` field in GameState
3. `Timer` component — formats and displays the time

The timer value (in seconds) is stored in `GameState.timer` so it can be saved/restored via localStorage (Story 3.2).

`useTimer` should accept a `paused` boolean prop. When the game is complete, pass `paused: true` to stop ticking.

### Key Patterns to Follow

```typescript
// useTimer hook
export function useTimer(onTick: () => void, paused: boolean) {
  useEffect(() => {
    if (paused) return;
    const interval = setInterval(onTick, 1000);
    return () => clearInterval(interval);
  }, [onTick, paused]);
}

// Timer component — format seconds to display
function formatTime(seconds: number): string {
  const h = Math.floor(seconds / 3600);
  const m = Math.floor((seconds % 3600) / 60);
  const s = seconds % 60;
  if (h > 0) return `${h}:${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
  return `${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
}

// Reducer
case 'TICK_TIMER':
  return { ...state, timer: state.timer + 1 };
```
