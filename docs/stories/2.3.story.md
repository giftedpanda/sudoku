# Story 2.3: Erase and Cell Clearing

## Status
Draft

## Story
**As a** player,
**I want** to erase a cell's value using an erase button or the Delete/Backspace key,
**so that** I can correct mistakes.

## Acceptance Criteria
1. An "Erase" button is displayed in the action bar
2. Clicking Erase clears the selected cell's value and notes
3. Pressing Delete or Backspace clears the selected cell
4. Given cells cannot be erased
5. Erasing pushes an undo entry
6. Error flags are recalculated after erasing
7. The erase button is visually clear with an appropriate icon/label

## Dev Notes

### Architecture Context
The `ActionBar` component will eventually hold multiple action buttons (Erase, Pencil toggle, Undo). This story creates the component with just the Erase button. Stories 2.4 and 2.6 will add more buttons.

The `ERASE_CELL` reducer action:
1. Ignores if no cell is selected
2. Ignores if the selected cell is given
3. Pushes undo entry
4. Sets cell value to null and clears notes
5. Revalidates the board

### Key Patterns to Follow

```typescript
// Reducer — ERASE_CELL action
case 'ERASE_CELL': {
  if (!state.selectedCell) return state;
  const { row, col } = state.selectedCell;
  const cell = state.board[row][col];
  if (cell.isGiven) return state;
  if (cell.value === null && cell.notes.size === 0) return state; // nothing to erase

  const undoEntry: UndoAction = { position: { row, col }, previousCell: { ...cell, notes: new Set(cell.notes) } };
  const newBoard = cloneBoard(state.board);
  newBoard[row][col] = { ...newBoard[row][col], value: null, notes: new Set() };

  return {
    ...state,
    board: validateBoard(newBoard),
    undoStack: [...state.undoStack, undoEntry],
  };
}

// ActionBar
interface ActionBarProps {
  onErase: () => void;
  onTogglePencil: () => void;  // wired in Story 2.4
  onUndo: () => void;          // wired in Story 2.6
  isPencilMode: boolean;
  canUndo: boolean;
}
```
