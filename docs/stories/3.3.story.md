# Story 3.3: Puzzle Completion Detection and Celebration

## Status
Draft

## Story
**As a** player,
**I want** the game to detect when I've solved the puzzle and show a celebration,
**so that** I feel a sense of accomplishment.

## Acceptance Criteria
1. When all cells are filled correctly (matching the solution), the game detects completion
2. A celebration overlay appears with a congratulatory message
3. The overlay shows the completion time and difficulty
4. The timer stops when the puzzle is complete
5. The celebration overlay has a "New Game" button to start another puzzle
6. The completion state is persisted (no re-celebration on page reload)
7. The overlay has a smooth entrance animation

## Dev Notes

### Architecture Context
Completion detection is built into the reducer flow:
1. After `SET_VALUE`, the reducer calls `isBoardComplete(board, solution)`
2. If true, sets `isComplete: true`
3. The `useTimer` hook receives `paused: isComplete` and stops ticking
4. `GameBoard` conditionally renders `CompletionOverlay`

The overlay should be visually prominent — full-screen semi-transparent backdrop with a centered card.

On completion, either clear the localStorage save or save with `isComplete: true` so that on reload it shows the completed state rather than replaying the celebration.
