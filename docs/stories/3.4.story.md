# Story 3.4: Responsive Layout — Mobile

## Status
Draft

## Story
**As a** mobile player,
**I want** the game to fit and look great on my phone screen,
**so that** I can play comfortably on small devices.

## Acceptance Criteria
1. The grid fills the available width on screens < 640px (sm breakpoint)
2. Cells are large enough for comfortable touch interaction (minimum 40x40px)
3. The number pad buttons are large and spaced for touch (minimum 44x44px tap targets)
4. The layout is vertical: header > grid > action bar > number pad
5. No horizontal scrolling occurs on any mobile viewport
6. Text is readable without zooming
7. The game is usable on viewports as small as 320px wide

## Tasks / Subtasks
- [ ] Set grid to `w-full max-w-md` with aspect-ratio-based cell sizing
- [ ] Set cells to scale with container using CSS Grid or percentage widths
- [ ] Style NumberPad for mobile: full-width grid of 9 buttons
- [ ] Style ActionBar for mobile: horizontal button row
- [ ] Style GameHeader for mobile: compact layout
- [ ] Test on multiple viewport sizes (320px, 375px, 414px)
- [ ] Verify no overflow/scroll issues
- [ ] Write visual regression tests or snapshot tests
- [ ] Run full test suite
- [ ] Self-verify with Definition of Done

## Dev Notes

### Architecture Context
This is a CSS/layout story — no new logic. The goal is to make the existing components responsive for mobile viewports using Tailwind's responsive utilities.

The key constraint is the Sudoku grid: it must be square, and each cell must be touchable. On a 320px viewport, each cell would be ~33px (320/9 - borders), which is slightly below the 40px target. Use `min-w-[320px]` and allow slight horizontal padding.

Layout order (mobile, vertical stack):
1. GameHeader (difficulty, timer, new game button)
2. SudokuGrid (square, full width)
3. ActionBar (erase, pencil, undo buttons)
4. NumberPad (3x3 grid of number buttons)

### Key Patterns to Follow

```typescript
// GameBoard layout — mobile first
<div className="flex flex-col items-center gap-4 p-4 max-w-md mx-auto">
  <GameHeader />
  <SudokuGrid />
  <ActionBar />
  <NumberPad />
</div>

// Grid — responsive sizing
<div className="grid grid-cols-9 w-full aspect-square">
  {/* cells */}
</div>

// NumberPad — mobile touch targets
<div className="grid grid-cols-9 gap-1 w-full">
  {[1,2,3,4,5,6,7,8,9].map(n => (
    <button key={n} className="aspect-square min-h-[44px] text-lg font-semibold">
      {n}
    </button>
  ))}
</div>
```
