# Story 1.5: Basic Grid Rendering

## Status
Draft

## Story
**As a** player,
**I want** to see a 9x9 Sudoku grid with clear 3x3 box borders,
**so that** I can visually parse the puzzle layout.

## Acceptance Criteria
1. A 9x9 grid of cells renders on the page
2. 3x3 box boundaries are visually distinct (thicker borders)
3. Given (pre-filled) cells display their number in a bold/distinct style
4. Empty cells appear blank
5. The grid renders a hardcoded puzzle correctly (for now)
6. The grid is visually centered on the page
7. Component tests verify grid structure and cell rendering

## Dev Notes

### Architecture Context
This story introduces the first UI components. The grid displays a static puzzle — no interaction yet (that comes in Story 2.1+). Use a hardcoded puzzle for testing. The actual puzzle generation integration happens later.

`GameBoard` is the main orchestrator that will eventually hold all game state. For now, it just passes a hardcoded board to `SudokuGrid`.

### Key Patterns to Follow

```typescript
// SudokuCell — a single cell in the grid
interface SudokuCellProps {
  cell: Cell;
  position: Position;
  isSelected: boolean;     // will be used in story 2.1
  isHighlighted: boolean;  // will be used in story 2.1
  onClick: (position: Position) => void;
}

// SudokuGrid — the 9x9 grid
interface SudokuGridProps {
  board: Board;
  selectedCell: Position | null;
  onCellClick: (position: Position) => void;
}

// Use Tailwind for box borders:
// - Thicker border on cells at box boundaries (col % 3 === 0, row % 3 === 0)
// - Standard border between other cells
```

Box border logic: cells where `col % 3 === 0` get a thicker left border; cells where `row % 3 === 0` get a thicker top border. Right and bottom borders of the grid also thick.
