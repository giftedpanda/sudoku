# Story 2.2: Number Input

## Status
Draft

## Story
**As a** player,
**I want** to enter numbers into empty cells by clicking a number pad or pressing 1-9,
**so that** I can solve the puzzle.

## Acceptance Criteria
1. A number pad (1-9) is displayed below the grid
2. Clicking a number pad button fills the selected cell with that number
3. Pressing keys 1-9 on the keyboard fills the selected cell with that number
4. Given (pre-filled) cells cannot be modified
5. Entering a number on a cell that already has a value replaces it
6. The input is handled through the `SET_VALUE` reducer action
7. The number pad is visually clear with large, tappable buttons
8. Component tests verify input behavior

## Dev Notes

### Architecture Context
This story adds the `SET_VALUE` action to the reducer and introduces the NumberPad component. The reducer must:
1. Ignore the action if no cell is selected
2. Ignore the action if the selected cell is a given cell (`isGiven === true`)
3. Push an `UndoAction` before modifying the cell (for Story 2.6)
4. Clear notes on the cell when a value is set
5. Call `validateBoard()` after setting the value to update error flags

The NumberPad shows buttons for 1-9. Each button dispatches `SET_VALUE`.

### Key Patterns to Follow

```typescript
// Reducer — SET_VALUE action
case 'SET_VALUE': {
  if (!state.selectedCell) return state;
  const { row, col } = state.selectedCell;
  const cell = state.board[row][col];
  if (cell.isGiven) return state;

  // Push undo before changing
  const undoEntry: UndoAction = { position: { row, col }, previousCell: { ...cell, notes: new Set(cell.notes) } };

  const newBoard = cloneBoard(state.board);
  newBoard[row][col] = {
    ...newBoard[row][col],
    value: action.value,
    notes: new Set(),
  };

  return {
    ...state,
    board: validateBoard(newBoard),
    undoStack: [...state.undoStack, undoEntry],
  };
}

// NumberPad component
interface NumberPadProps {
  onNumberClick: (value: number) => void;
  disabled: boolean;
}
```
