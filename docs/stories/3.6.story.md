# Story 3.6: Keyboard Navigation

## Status
Draft

## Story
**As a** keyboard user,
**I want** to navigate the grid and interact with the game using only the keyboard,
**so that** I can play efficiently without a mouse.

## Acceptance Criteria
1. Arrow keys move the selection between cells (up/down/left/right)
2. Arrow navigation wraps at grid boundaries (right from col 8 goes to col 0 of next row, etc.)
3. Tab moves to the next interactive element (grid > number pad > action bar)
4. Number keys 1-9 input values (already done in Story 2.2, verify integration)
5. Delete/Backspace erases the selected cell (already done in Story 2.3, verify integration)
6. Ctrl+Z / Cmd+Z triggers undo (already done in Story 2.6, verify integration)
7. The selected cell has a visible focus indicator
8. Focus is trapped logically within the game area

## Dev Notes

### Architecture Context
This story adds arrow key navigation on top of the existing keyboard handling. The `GameBoard` already listens for keyboard events (from Stories 2.2, 2.3, 2.6). This story extends the handler.

Arrow key logic:
- ArrowUp: row - 1 (wrap to row 8 if at row 0)
- ArrowDown: row + 1 (wrap to row 0 if at row 8)
- ArrowLeft: col - 1 (wrap to col 8 and row - 1 if at col 0)
- ArrowRight: col + 1 (wrap to col 0 and row + 1 if at col 8)

The grid should use a roving tabindex pattern:
- Only the selected cell has `tabIndex={0}`
- All other cells have `tabIndex={-1}`
- This keeps the tab order clean while allowing arrow key navigation within the grid

### Key Patterns to Follow

```typescript
// Arrow key navigation in GameBoard
const handleKeyDown = (e: KeyboardEvent) => {
  if (!state.selectedCell) return;
  const { row, col } = state.selectedCell;
  let newRow = row, newCol = col;

  switch (e.key) {
    case 'ArrowUp':
      newRow = row === 0 ? 8 : row - 1;
      break;
    case 'ArrowDown':
      newRow = row === 8 ? 0 : row + 1;
      break;
    case 'ArrowLeft':
      if (col === 0) { newCol = 8; newRow = row === 0 ? 8 : row - 1; }
      else { newCol = col - 1; }
      break;
    case 'ArrowRight':
      if (col === 8) { newCol = 0; newRow = row === 8 ? 0 : row + 1; }
      else { newCol = col + 1; }
      break;
  }
  dispatch({ type: 'SELECT_CELL', position: { row: newRow, col: newCol } });
};

/>
```
