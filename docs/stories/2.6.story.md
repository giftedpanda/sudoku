# Story 2.6: Undo Functionality

## Status
Draft

## Story
**As a** player,
**I want** to undo my last action,
**so that** I can easily reverse mistakes without manually erasing.

## Acceptance Criteria
1. An "Undo" button is displayed in the ActionBar
2. Clicking Undo restores the previously modified cell to its prior state
3. Multiple undos can be performed sequentially (the entire undo stack)
4. Undo restores both values and notes
5. The Undo button is disabled when the undo stack is empty
6. Pressing Ctrl+Z / Cmd+Z triggers undo
7. Undo revalidates the board after restoring

## Dev Notes

### Architecture Context
Undo entries are pushed by `SET_VALUE`, `ERASE_CELL`, and `TOGGLE_NOTE` actions (already implemented in those stories). Each entry stores the position and the full previous cell state.

The `UNDO` action:
1. Pops the last entry from the undo stack
2. Restores the cell at the stored position to its previous state
3. Revalidates the board
4. Does nothing if the stack is empty

The undo stack is a simple array — no redo support. Starting a new game clears the stack.

### Key Patterns to Follow

```typescript
// Reducer — UNDO action
case 'UNDO': {
  if (state.undoStack.length === 0) return state;

  const newStack = [...state.undoStack];
  const entry = newStack.pop()!;

  const newBoard = cloneBoard(state.board);
  newBoard[entry.position.row][entry.position.col] = entry.previousCell;

  return {
    ...state,
    board: validateBoard(newBoard),
    undoStack: newStack,
  };
}

// Keyboard shortcut in GameBoard
useEffect(() => {
  const handler = (e: KeyboardEvent) => {
    if ((e.ctrlKey || e.metaKey) && e.key === 'z') {
      e.preventDefault();
      dispatch({ type: 'UNDO' });
    }
  };
  window.addEventListener('keydown', handler);
  return () => window.removeEventListener('keydown', handler);
}, [dispatch]);
```
