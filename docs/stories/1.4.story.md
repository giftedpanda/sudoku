# Story 1.4: Puzzle Solver and Validator

## Status
Draft

## Story
**As a** developer,
**I want** a Sudoku solver that can find solutions and count solution uniqueness,
**so that** the generator can verify puzzles and the game can validate completeness.

## Acceptance Criteria
1. `solve(board)` returns a complete valid solution or `null` if unsolvable
2. `countSolutions(board, limit)` counts solutions up to `limit` (returns early once limit is reached)
3. Solver correctly handles empty boards, partially filled boards, and already-complete boards
4. Solver returns `null` for boards with conflicts (invalid starting state)
5. `isValidPlacement(board, pos, value)` correctly checks row/column/box constraints
6. Performance: solver completes in under 500ms for typical puzzles
7. All functions have comprehensive unit tests with known puzzles

## Dev Notes

### Architecture Context
The solver uses backtracking with constraint checking. It operates on raw `CellValue[][]` arrays (not `Board` objects) to keep it lightweight and independent of the Cell type.

**Algorithm:**
1. Find the first empty cell (null value)
2. If no empty cell exists, the board is solved — return it
3. For each candidate 1-9:
   a. Check if placing candidate at this cell is valid (no row/col/box conflict)
   b. If valid, place it and recurse
   c. If recursion succeeds, return the result
4. If no candidate works, return null (backtrack)

`countSolutions` is similar but instead of returning on the first solution, it increments a counter and continues until the counter reaches `limit`.

The solver creates a deep copy of the input board before mutating it. The original is never modified.
