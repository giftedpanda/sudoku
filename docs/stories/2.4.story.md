# Story 2.4: Pencil/Notes Mode

## Status
Draft

## Story
**As a** player,
**I want** to toggle pencil mode and enter small candidate numbers as notes in cells,
**so that** I can track possible values while solving.

## Acceptance Criteria
1. A "Pencil" toggle button is displayed in the ActionBar
2. Clicking the Pencil button toggles pencil mode on/off with a visual indicator
3. When pencil mode is ON and a number is entered, it toggles a note (add/remove) instead of setting a value
4. Notes are displayed as small numbers (1-9) arranged in a 3x3 grid within the cell
5. Setting a value on a cell with notes clears the notes
6. Notes can only be added to cells without a value
7. Toggling a note that already exists removes it
8. Notes mode is persisted in game state (`isPencilMode`)

## Dev Notes

### Architecture Context
Notes are stored as `Set<number>` on each `Cell`. The `TOGGLE_NOTE` action:
1. Ignores if no cell selected
2. Ignores if cell is given
3. Ignores if cell already has a value (must erase first)
4. If the note exists in the set, removes it; if not, adds it
5. Pushes undo entry before modifying

The `GameBoard` orchestrator checks `isPencilMode` and dispatches either `SET_VALUE` or `TOGGLE_NOTE` when a number is pressed.

Notes rendering in `SudokuCell`: display a 3x3 mini-grid where position (0,0) = 1, (0,1) = 2, ..., (2,2) = 9. Only show numbers that are in the notes Set.

### Key Patterns to Follow

```typescript
// Reducer actions
case 'TOGGLE_PENCIL_MODE':
  return { ...state, isPencilMode: !state.isPencilMode };

case 'TOGGLE_NOTE': {
  if (!state.selectedCell) return state;
  const { row, col } = state.selectedCell;
  const cell = state.board[row][col];
  if (cell.isGiven || cell.value !== null) return state;

  const undoEntry: UndoAction = { position: { row, col }, previousCell: { ...cell, notes: new Set(cell.notes) } };
  const newNotes = new Set(cell.notes);
  if (newNotes.has(action.value)) {
    newNotes.delete(action.value);
  } else {
    newNotes.add(action.value);
  }

  const newBoard = cloneBoard(state.board);
  newBoard[row][col] = { ...newBoard[row][col], notes: newNotes };

  return {
    ...state,
    board: newBoard,
    undoStack: [...state.undoStack, undoEntry],
  };
}
```
