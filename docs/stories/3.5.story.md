# Story 3.5: Responsive Layout — Desktop

## Status
Draft

## Story
**As a** desktop player,
**I want** the game layout to take advantage of larger screens,
**so that** the game looks polished and is comfortable to play on desktop.

## Acceptance Criteria
1. On screens >= 640px (sm), the layout shifts to a more spacious arrangement
2. The grid has a maximum width to prevent oversized cells (max ~500px)
3. The game is centered on the page with comfortable padding
4. Typography scales appropriately for larger screens
5. Hover states are added to interactive elements (cells, buttons)
6. The number pad and action bar are appropriately sized for mouse interaction
7. The overall page has a clean, modern look

## Dev Notes

### Architecture Context
This is a CSS/layout story for desktop viewports. It builds on the mobile-first layout from Story 3.4 by adding responsive overrides at the `sm:` and `md:` Tailwind breakpoints.

Desktop additions:
- Hover states on cells and buttons (not applicable on touch)
- Slightly larger text and spacing
- Max-width constraint so the grid doesn't grow too large on ultrawide screens
- Cursor pointer on clickable elements

### Key Patterns to Follow

```typescript
// Desktop overrides using Tailwind responsive prefixes
<div className="flex flex-col items-center gap-4 p-4 max-w-md mx-auto sm:max-w-lg sm:gap-6 sm:p-8">

// Hover states — only visible on desktop
<button className="... hover:bg-blue-50 transition-colors cursor-pointer">

// Cell hover
<button className="... hover:bg-gray-100 transition-colors">

// Desktop typography scaling
<span className="text-base sm:text-lg md:text-xl font-semibold">
```
