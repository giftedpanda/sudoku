# Story 3.1: Difficulty Selection and New Game Flow

## Status
Draft

## Story
**As a** player,
**I want** to choose a difficulty level and start a new game,
**so that** I can play puzzles that match my skill level.

## Acceptance Criteria
1. A "New Game" button is accessible in the game header
2. Clicking "New Game" opens a dialog with three difficulty options: Easy, Medium, Hard
3. Selecting a difficulty generates a new puzzle and resets the game state
4. The timer resets to 0 on new game
5. The undo stack is cleared on new game
6. Pencil mode is turned off on new game
7. The dialog can be dismissed without starting a new game
8. The current difficulty is displayed in the game header
9. On first load (no saved game), the new game dialog appears automatically

## Dev Notes

### Architecture Context
This story integrates the puzzle generator (Story 1.3) with the game UI. The `NEW_GAME` action completely replaces the game state:

```typescript
case 'NEW_GAME': {
  const board = createBoardFromPuzzle(action.puzzle); // convert CellValue[][] to Board
  return {
    board,
    solution: action.solution,
    difficulty: action.difficulty,
    selectedCell: null,
    isPencilMode: false,
    timer: 0,
    undoStack: [],
    isComplete: false,
  };
}
```

`createBoardFromPuzzle` is a helper that converts `CellValue[][]` to `Board`, setting `isGiven: true` for non-null cells.

The dialog should be simple — three buttons (Easy/Medium/Hard) and a Cancel button.

  return puzzle.map(row =>
