# Story 3.7: Accessibility and Screen Reader Support

## Status
Draft

## Story
**As a** screen reader user,
**I want** the game to be fully accessible with proper ARIA labels and announcements,
**so that** I can play Sudoku without relying on visual cues.

## Acceptance Criteria
1. The grid has `role="grid"` with each row as `role="row"` and each cell as `role="gridcell"`
2. Each cell has an `aria-label` describing its position and content (e.g., "Row 3, Column 5, value 7, given")
3. Cells with errors have `aria-invalid="true"`
4. The pencil mode state is announced when toggled (`aria-live` region or `aria-pressed`)
5. The timer has `aria-label` and is accessible as live content
6. The number pad buttons have descriptive `aria-label`s
7. The completion overlay is announced with `role="alertdialog"`
8. All interactive elements are reachable and operable by keyboard
9. Color is not the only indicator of state (errors, selection use both color and shape/text/icon)
10. The page passes WCAG AA automated checks (axe-core)

## Dev Notes

### Architecture Context
This story adds ARIA attributes and screen reader support across all game components. It does not change game logic — only markup and some visual additions for non-color indicators.

Key ARIA patterns:
- Grid: standard ARIA grid pattern (`role="grid"` > `role="row"` > `role="gridcell"`)
- Cells: descriptive labels including position (row/col), value, and state (given/error/empty)
- Buttons: `aria-label` on icon-only buttons, `aria-pressed` on toggles
- Live regions: `aria-live="polite"` for status messages (mode change, error count, completion)

WCAG AA requires:
- 4.5:1 contrast ratio for text
- 3:1 contrast ratio for UI components
- Non-color indicators for state
- Keyboard operability (covered in Story 3.6)
- Screen reader compatibility

### Key Patterns to Follow

```typescript
// SudokuGrid — grid role structure
<div role="grid" aria-label="Sudoku puzzle grid">
  {board.map((row, rowIndex) => (
    <div key={rowIndex} role="row">
      {row.map((cell, colIndex) => (
        <SudokuCell
          key={colIndex}
          role="gridcell"
          aria-label={getCellAriaLabel(cell, rowIndex, colIndex)}
          aria-invalid={cell.isError || undefined}
          // ...
        />
      ))}
    </div>
  ))}
</div>

// Cell aria-label helper
function getCellAriaLabel(cell: Cell, row: number, col: number): string {
  const position = `Row ${row + 1}, Column ${col + 1}`;
  if (cell.value === null) {
    const noteStr = cell.notes.size > 0 ? `, notes: ${Array.from(cell.notes).sort().join(', ')}` : '';
    return `${position}, empty${noteStr}`;
  }
  const given = cell.isGiven ? ', given' : '';
  const error = cell.isError ? ', error' : '';
  return `${position}, value ${cell.value}${given}${error}`;
}

// Pencil toggle — aria-pressed
<button
  aria-pressed={isPencilMode}
  aria-label="Pencil mode"
  onClick={onTogglePencil}
>

// CompletionOverlay — alertdialog
<div role="alertdialog" aria-labelledby="completion-title" aria-describedby="completion-desc">
  <h2 id="completion-title">Puzzle Complete!</h2>
  <p id="completion-desc">You solved the {difficulty} puzzle in {formattedTime}.</p>
</div>
```
