# Story 1.3: Puzzle Generator

## Status
Draft

## Story
**As a** player,
**I want** the game to generate valid Sudoku puzzles at different difficulty levels,
**so that** I always have a fresh, solvable puzzle to play.

## Acceptance Criteria
1. `generatePuzzle(difficulty)` returns a `{ puzzle, solution }` object
2. The `solution` is a valid, completely filled 9x9 Sudoku board
3. The `puzzle` is derived from the solution by removing cells
4. The puzzle has exactly one unique solution (verified by the solver)
5. Easy puzzles have 36-40 clues remaining
6. Medium puzzles have 30-35 clues remaining
7. Hard puzzles have 24-29 clues remaining
8. Generation completes in under 2 seconds for all difficulty levels
9. Generated puzzles are randomized (not the same board every time)
10. All functions have comprehensive unit tests

## Dev Notes

### Architecture Context
The generator depends on the solver (Story 1.4) to verify puzzle uniqueness. The algorithm:

1. **Generate a complete board:** Start with an empty 9x9 grid. Use backtracking with randomized candidate order (shuffle 1-9 for each cell) to fill the entire board.
2. **Remove cells:** Randomly select filled cells. For each, temporarily remove it and check if `countSolutions(board, 2) === 1`. If still unique, keep it removed. If not, restore it and try another cell. Continue until the target clue count is reached.

```typescript
export function generatePuzzle(difficulty: Difficulty): {
  puzzle: CellValue[][];
  solution: CellValue[][];
}
```

The puzzle is returned as a raw `CellValue[][]` (not `Board`). The UI layer converts it to `Board` with proper `Cell` objects.
